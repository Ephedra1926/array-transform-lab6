# Лабораторна робота №6 — Основи роботи з Git. Командна розробка

Проєкт виконано командою з трьох учасників у межах лабораторної роботи
«Основи роботи з Git. Робота з гілками: командна розробка».
Мета — базові навички командної роботи у системі контролю версій Git (GitHub).

## Завдання (Варіант 3)

Дано цілочисловий масив **A**, який складається з 12 елементів.
Створити масив **C**, який складається з остач ділення елементів масиву A
на ціле число **k** (k < 10), яке вводиться з клавіатури.
Обчислити добуток ненульових елементів масиву C.
Вивести на друк заданий і новоутворений масиви.

Особливий випадок: k може бути рівним 0 — передбачено окрему гілку
`feature/k-zero-case` з обробкою цієї ситуації.

## Розподіл роботи між учасниками

| Учасник                          | Гілка                     | Завдання                                                   |
|----------------------------------|---------------------------|------------------------------------------------------------|
| Табачук Марія (координатор)      | `main`                    | Базова версія програми, злиття гілок                       |
| Табачук Марія (координатор)      | `feature/formatted-output`| Форматований вивід масиву в рядок (пункт c)                |
| Табачук Марія (координатор)      | `feature/k-zero-case`     | Випадок k = 0 (пункт 8 методички)                          |
| Цюпяк Данило                     | `feature/keyboard-input`  | Введення елементів масиву та розміру з клавіатури (пункт a)|
| Цимбалістий Артем                | `feature/random-fill`     | Заповнення масиву генератором випадкових чисел (пункт b)   |

Розподіл підзадач між учасниками виконано у системі Trello.

## Структура гілок

- `main` — основна гілка, базова версія програми
- `feature/keyboard-input` — варіант введення масиву з клавіатури
- `feature/random-fill` — варіант заповнення масиву випадковими числами
- `feature/formatted-output` — форматований вивід масиву
- `feature/k-zero-case` — обробка випадку k = 0

## Як зібрати і запустити

Потрібен компілятор GCC (MinGW на Windows / gcc на Linux):

    gcc main.c -o lab6
    ./lab6        (Windows PowerShell: .\lab6.exe)

## Основні команди, які використовувались у роботі

    git clone   — клонування репозиторію
    git checkout -b <гілка> — створення гілки і перехід у неї
    git add     — додавання змінених файлів
    git commit  — фіксація змін
    git push    — відправлення змін у віддалений репозиторій
    git pull    — отримання змін з віддаленого репозиторію
    git merge   — злиття гілок
